# MO05. MO2's plugin groups: the plugin manager extension and its `plugingroups.txt`

## 1. Source

- MO2 itself has no groups in its plugin list: its source (MO01's, `master` at `4ba22f0`, and the branches `2_5_x`
  and `dev/extensions` as they stood on 2026-11-23) names no such file and no such thing. **FACT.**
- The groups come from an extension, "Bethesda Plugin Manager for Mod Organizer", which takes the place of MO2's
  own plugin list: `github.com/Exit-9B/modorganizer-bsplugins`, `main` at `5c535d7` (2024-02-15), GPL-3.0 by its
  `LICENSE`. Read only, cited as file and line; nothing of it is copied. ModTrap's own code
  (`modtrap/plugingroups.py`) is written from the facts below (MT73).
- **LIKELY.** The owner's MO2 runs this extension or a fork of it (one is published that says it reads and writes
  the same file, and keeps two more files of its own in the profile, which the owner's profile does not have).
  Which version is not known. What is known is the file itself: §5.

## 2. The file

- **FACT (`src/TESData/PluginList.cpp:198-205`).** It is `plugingroups.txt` in the profile's folder.
- **FACT (`:1124-1160`).** Reading: every plugin's group is cleared first. Then line by line: an empty line and a
  line that begins with `#` say nothing; any other line is split at `|` and must give exactly two fields, the
  plugin's file name and the group's name (a line that does not is reported in MO2's log and passed over). A name
  the plugin list does not have is passed over without a word. Names are found without regard to case.
- **FACT (`:1172-1187`).** Writing: the whole file anew. First the line
  `# This file was automatically generated by Mod Organizer.`, then one line for each plugin that has a group,
  `name|group`, in the order of the plugins' file names, each ended CR LF, in UTF-8. A plugin without a group has
  no line.
- **FACT (`:218-232`, `:801-812`, `:547-556`).** It is read at every refresh of the plugin list, and written
  whenever the plugin lists are written (with `plugins.txt` and `loadorder.txt`) and when a group is set.
- **So:** a line for a plugin that is no longer in the list does no harm and is gone at MO2's next write; and an
  open MO2 writes its own groups back over a change made beside it, as it does with its other lists (MO01§2).

## 3. What a group is

- **FACT (`src/BSPluginList/PluginGroupProxyModel.cpp:453-530`).** A group has no record of its own. With the
  list in the load order's order, a group's line is begun wherever a plugin's group name is not the one of the
  plugin before it; a plugin without a group stands by itself, outside any group. A name that comes again after
  other plugins makes another group of the same name (the extension counts them, `:487`, `:504`). The line after
  the game's own plugins, and the one after the last master, end a group too (`:519-527`).
- **So:** a group is a run of neighbours in the load order that carry the same name. Where a plugin stands decides
  what the groups look like, not the file alone.

## 4. A plugin moved

- **FACT (`src/TESData/PluginList.cpp:359-422`).** When a plugin is moved, its group is worked out anew: where the
  plugin it lands on and that one's neighbour on the far side are in one group, it joins that group; otherwise it
  keeps its own unless the move took it away from neighbours of its own group, in which case it has none (it
  keeps its own all the same where it lands on a plugin of it).
- ModTrap's rule for its own moves (MT73) says the same in its own words and is written from this description,
  not from the code.

## 5. The owner's file

**FACT (a session's pack of 2026-11-23; the file stays with the owner, and no name from it is kept here).**

- 3,741 lines for a load order of 3,742 plugins, after the one comment line of §2; every line has one `|`; the
  lines are in the order of the plugins' names without regard to case; the lines end CR LF; there is no byte-order
  mark and no letter outside ASCII.
- 63 different group names. In the load order each of them is one run: no name comes twice.
- 26 of the 63 names are also names of separators of the mod list; the others are the list author's own.
- The one plugin without a line is the one ModTrap had installed the same day: nothing gives a new plugin a group
  but the owner's own hand in MO2, or, from MT73 on, ModTrap.
